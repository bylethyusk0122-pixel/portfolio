01 / The brief

今回の依頼者は、自分自身です。

物販経験をまとめた記事、商品LP、マニュアル動画。単体では見せられても、何を頼める人なのかが伝わりにくい状態でした。そこで「複雑な内容を整理し、買う前と使う時の説明を揃える」という一つの仕事に再設計しました。

整理する前

  • 記事、LP、動画が別々に見える
  • 使える技術の一覧で終わる
  • 依頼後の完成像が想像しにくい
→

整理した後

  • 商品を伝える目的で統一
  • 必要な制作物をまとめて相談できる
  • 企画から納品までの範囲が見える

03 / Best fit

「何を作るか」から整理したい依頼に向いています。

商品の良さは分かるが、説明の順番が決まらない

LPと記事で言っていることを揃えたい

問い合わせのたびに同じ説明を繰り返している

撮影や出演なしで解説動画を用意したい

向いていない依頼

広告運用による売上保証、人間の声が価値になるナレーション、実写撮影が中心の動画、大規模なWordPress開発は対象外です。できる範囲を広く見せず、納品後に自分で確認できる制作だけを受けます。

04 / Why me

売る現場と、作る工程の両方から考えます。

物販の実体験から整理する

商品を並べるだけでは伝わらないこと、購入前の迷い、説明不足による行き違いを経験しています。体験を誇張せず、買う側が判断できる情報へ変えます。

見た目で終わらせず、動く形にする

LPは構成・文章・デザイン・HTML/CSSまで、動画は原稿・合成音声・字幕・完成ファイルまで。実際に開いて確認できるものを納品します。

AIは制作速度のために使う

構成案、実装、検査の補助にAIを使用します。ただし、事実確認と完成物の判断は人が行い、AIが作ったこと自体を価値にはしません。

連絡方法を先に揃える

通常の連絡はメール・チャットで完結。オンライン面談が必要な場合は月曜日を基本に調整し、制作前に納品物・修正回数・期限を文章で揃えます。

05 / Deliverables

依頼内容に合わせて、必要なものだけ選べます。

記事・構成

ヒアリング、読者設定、見出し構成、本文、掲載前の整合確認。

LP・Webページ

目的整理、構成、コピー、デザイン、レスポンシブ実装、表示確認。

解説・マニュアル動画

原稿整理、VOICEPEAK音声、スライド、字幕、MP4と字幕データ。

06 / Process

最初に作るものを決めるところから。

  1. 目的を聞く誰に、何を理解・判断・操作してほしいか確認します。
  2. 制作物を絞る記事、LP、動画のうち必要なものと役割を決めます。
  3. 一つずつ確認する構成から初稿、修正へ。途中で完成像を確認できます。
  4. 使える形で納品公開ページ、HTML一式、MP4、字幕などを揃えます。

Start with the problem

まだ、何を作るか決まっていなくても大丈夫です。

商品やサービスの内容と、いま説明に困っていることを送ってください。記事、LP、動画のどれが必要かから整理します。

連絡はメール・チャット中心。オンライン面談は月曜日を基本に調整します。電話での常時対応は行っていません。
